# Changelog
This document records major changes to the asc-comm repository.

## Unreleased

### Added
- Added entry for project documentation, Quick Start, Build & Test, third-party dependencies and compatibility specifications.
- Added API reference documentation for AICore Hcomm point-to-point communication interfaces, covering `Hcomm`, `Init`, `ReadNbi`, `WriteNbi`, `WriteWithNotifyNbi`, `AtomicFAA`, `AtomicCAS`, `Commit`, and `Drain`.
- Added sample entry `hcomm_write_read_nbi` for AICore Hcomm, demonstrating the two-card point-to-point communication workflow using `WriteNbi` and `ReadNbi`.
- Added issue templates, contribution guidelines and resource contribution instructions.

### Notes
- Currently available public capabilities mainly cover AICore Hcomm point-to-point communication interfaces.
