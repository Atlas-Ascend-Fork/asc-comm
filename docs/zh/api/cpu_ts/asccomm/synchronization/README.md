# 简介

本节提供CPU_TS Asccomm的同步接口：`asccomm_cpu_thread_notify_record_on_thread`用于向目标AI CPU线程发送通知，`asccomm_cpu_thread_notify_wait_on_thread`用于向本Host CPU线程的Host Stream提交等待通知任务。两个接口需配合使用。
