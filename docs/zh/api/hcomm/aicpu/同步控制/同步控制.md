# 同步控制

同步控制接口用于实现通信线程之间、通信线程与Runtime任务之间以及Channel两端之间的同步，并控制Channel读写任务的执行顺序和完成状态。

## 线程间同步

一个通信线程向另一个通信线程发送Notify信号，接收方线程等待信号到达后继续执行。

- **[HcommThreadNotifyRecordOnThread](./HcommThreadNotifyRecordOnThread.md)**：当前通信线程向目标线程发送Notify信号。
- **[HcommThreadNotifyWaitOnThread](./HcommThreadNotifyWaitOnThread.md)**：当前通信线程等待指定Notify信号，由调用者传入超时时间。
- **[HcommThreadNotifyWaitOnThreadWithDefaultTimeout](./HcommThreadNotifyWaitOnThreadWithDefaultTimeout.md)**：当前通信线程等待指定Notify信号，使用预先设置的默认超时时间。

## Runtime任务同步

通信线程发送或等待ACL Runtime提供的Notify信号，与其他Runtime任务同步。

- **[HcommAclrtNotifyRecordOnThread](./HcommAclrtNotifyRecordOnThread.md)**：通信线程发送指定的Runtime Notify信号。
- **[HcommAclrtNotifyWaitOnThread](./HcommAclrtNotifyWaitOnThread.md)**：通信线程等待指定的Runtime Notify信号。

## Channel两端同步

本端通过Channel向对端发送Notify信号，对端等待对应的Notify信号后继续执行。

- **[HcommChannelNotifyRecordOnThread](./HcommChannelNotifyRecordOnThread.md)**：指定通信线程，通过Channel向对端发送Notify信号。
- **[HcommChannelNotifyRecord](./HcommChannelNotifyRecord.md)**：通过Channel向对端发送Notify信号。
- **[HcommChannelNotifyWaitOnThread](./HcommChannelNotifyWaitOnThread.md)**：指定通信线程，等待对端发送的Notify信号，由调用者传入超时时间。
- **[HcommChannelNotifyWait](./HcommChannelNotifyWait.md)**：等待对端发送的Notify信号，由调用者传入超时时间。
- **[HcommChannelNotifyWaitOnThreadWithDefaultTimeout](./HcommChannelNotifyWaitOnThreadWithDefaultTimeout.md)**：指定通信线程，等待对端发送的Notify信号，使用预先设置的默认超时时间。

## Channel读写顺序

在Channel的读写任务之间插入Fence，确保Fence之前的读写完成后，才执行Fence之后的读写。

- **[HcommChannelFenceOnThread](./HcommChannelFenceOnThread.md)**：在指定通信线程和Channel上插入Fence，对Fence前后的读写任务保序。
- **[HcommChannelFence](./HcommChannelFence.md)**：在指定Channel上插入Fence，对Fence前后的读写任务保序。

## 任务完成等待

用于等待指定范围内已提交的任务完成。

- **[HcommFenceOnThread](./HcommFenceOnThread.md)**：对已初始化的数据面Flush资源执行全局Flush，并等待Flush完成，不限定某一个Channel。
- **[HcommChannelDrainOnThread](./HcommChannelDrainOnThread.md)**：等待指定通信线程和Channel上已提交的读写任务全部完成，直到任务队列为空。

## 超时设置

用于统一设置不显式传入超时参数的Notify信号等待接口所使用的默认超时时间。

- **[HcommSetNotifyWaitTimeOut](./HcommSetNotifyWaitTimeOut.md)**：设置Thread和Channel默认超时等待接口使用的超时时间。
