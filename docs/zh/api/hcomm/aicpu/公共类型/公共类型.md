# 公共类型

公共类型目录介绍AICPU Hcomm数据面API使用的句柄、数据类型、规约操作类型以及批量传输任务的描述方式。

- **[ThreadHandle](./ThreadHandle.md)**：线程句柄，用于指定提交和执行数据面任务的通信线程。
- **[ChannelHandle](./ChannelHandle.md)**：通道句柄，用于指定远端数据操作和Channel同步操作使用的通信通道。
- **[HcommDataType](./HcommDataType.md)**：数据类型枚举，用于指定本地规约和远端规约操作处理的元素类型。
- **[HcommReduceOp](./HcommReduceOp.md)**：规约操作枚举，用于指定求和、求积、最大值或最小值等规约方式。
- **[HcommTransferType](./HcommTransferType.md)**：批量传输类型枚举，用于指定单个批量传输任务执行读、写、规约或通知操作。
- **[HcommBatchTransferDesc](./HcommBatchTransferDesc.md)**：批量传输描述结构，用于设置单个传输任务的类型、内存地址、数据量、规约参数或通知索引。
