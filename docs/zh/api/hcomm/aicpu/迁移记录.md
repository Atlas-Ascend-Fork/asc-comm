- `HcommWriteNbiOnThread`
- `HcommWriteNbi`
- `HcommWriteWithNotifyNbiOnThread`
- `HcommWriteWithNotifyNbi`
- `HcommReadNbiOnThread`
- `HcommReadNbi`
- `HcommChannelNotifyRecord`
- `HcommChannelNotifyWait`
- `HcommFenceOnThread`
- `HcommChannelFence`
