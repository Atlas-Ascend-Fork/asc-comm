# 远端数据操作

远端数据操作接口用于通过Channel在本端和对端内存之间传输数据。写操作将本端源数据写入对端目标内存，读操作将对端源数据读入本端目标内存。

## 写操作

- **[HcommWriteOnThread](./HcommWriteOnThread.md)**：在指定通信线程和Channel上异步提交写操作。
- **[HcommWriteReduceOnThread](./HcommWriteReduceOnThread.md)**：将本端数据写入对端，并与对端目标内存中的数据执行规约操作。
- **[HcommWriteWithNotifyOnThread](./HcommWriteWithNotifyOnThread.md)**：在指定通信线程和Channel上提交写操作，并向对端发送Notify信号。
- **[HcommWriteReduceWithNotifyOnThread](./HcommWriteReduceWithNotifyOnThread.md)**：将本端数据写入对端并执行规约操作，同时向对端发送Notify信号。
- **[HcommWriteNbiOnThread](./HcommWriteNbiOnThread.md)**：在指定通信线程和Channel上非阻塞提交写操作。
- **[HcommWriteNbi](./HcommWriteNbi.md)**：在指定Channel上非阻塞提交写操作。
- **[HcommWriteWithNotifyNbiOnThread](./HcommWriteWithNotifyNbiOnThread.md)**：在指定通信线程和Channel上非阻塞提交写操作，并向对端发送Notify信号。
- **[HcommWriteWithNotifyNbi](./HcommWriteWithNotifyNbi.md)**：在指定Channel上非阻塞提交写操作，并向对端发送Notify信号。

## 读操作

- **[HcommReadOnThread](./HcommReadOnThread.md)**：在指定通信线程和Channel上异步提交读操作。
- **[HcommReadReduceOnThread](./HcommReadReduceOnThread.md)**：将对端数据读入本端，并与本端目标内存中的数据执行规约操作。
- **[HcommReadNbiOnThread](./HcommReadNbiOnThread.md)**：在指定通信线程和Channel上非阻塞提交读操作。
- **[HcommReadNbi](./HcommReadNbi.md)**：在指定Channel上非阻塞提交读操作。

## 批量读写

- **[HcommBatchTransferOnThread](./HcommBatchTransferOnThread.md)**：在指定通信线程和Channel上异步提交一组远端数据操作。
