# 概述

AICPU Hcomm数据面API提供通信域使用、任务管理、本地和远端数据操作以及同步控制能力。

- **[公共类型](../公共类型/公共类型.md)**：介绍数据面API使用的线程和通道句柄、数据类型、规约操作类型及批量传输描述结构。
- **[通信域使用](../通信域使用/通信域使用.md)**：提供按通信域ID获取、锁定和释放已创建通信域的接口。
- **[任务管理](../任务管理/任务管理.md)**：提供批量组织和提交数据面操作，以及配置任务队列等待超时的接口。
- **[本地数据操作](../本地数据操作/本地数据操作.md)**：提供Device内存间的本地拷贝和本地规约接口。
- **[远端数据操作](../远端数据操作/远端数据操作.md)**：提供通过Channel在本端与对端内存之间执行读、写、规约、通知和批量传输的接口。
- **[同步控制](../同步控制/同步控制.md)**：提供线程、Runtime任务和Channel两端同步，以及读写保序、完成等待和超时设置接口。
