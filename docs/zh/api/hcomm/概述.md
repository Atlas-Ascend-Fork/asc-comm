# HCOMM概述

HCOMM（Huawei Communication，华为通信基础库）是HCCL的通信基础库，为通信算子提供拓扑查询、通信资源管理、数据搬运和同步等能力。HCOMM将通信能力划分为控制面和数据面：控制面负责准备通信所需的拓扑信息和资源，数据面负责使用这些资源执行通信操作。

本资料主要介绍HCOMM数据面接口，并说明数据面使用控制面资源的总体流程。控制面接口资料由[HCOMM仓](https://gitcode.com/cann/hcomm)维护，本文仅提供相关入口，不涉及通信算法或算子的具体实现。

## 整体结构

| 层次 | 主要作用 | 资料组织 |
| --- | --- | --- |
| 控制面 | 查询通信域拓扑，创建或获取Thread、Channel、通信内存等资源，并管理资源生命周期。 | 控制面接口资料由[HCOMM仓](https://gitcode.com/cann/hcomm)维护，本文提供分类入口。 |
| 数据面 | 基于控制面提供的资源执行本地或远端数据操作，并完成通信任务之间的同步。 | 本仓的数据面资料按AICPU和AIV两部分组织。 |

控制面和数据面共同完成一次通信过程，典型流程如下：

1. **查询拓扑**：获取通信域内的rank数量、拓扑层级、rank间连接关系和可用链路。
2. **准备资源**：根据通信引擎和通信关系创建或获取Thread、Notify、Channel及通信内存，并准备Device侧执行所需的资源上下文。
3. **执行数据面操作**：在AICPU或AIV上执行本地拷贝、规约、远端读写和同步等操作。
4. **等待任务完成**：通过Notify、Fence或完成等待接口协调不同执行流，并确认已提交的通信任务达到所需的完成状态。
5. **复用或释放资源**：通信结束后，根据资源生命周期复用或释放Thread、Channel、通信内存及相关上下文。

## 控制面

控制面通常在Host侧为数据面准备拓扑信息和通信资源。相关接口资料由[HCOMM仓](https://gitcode.com/cann/hcomm)维护，主要包括以下几类：

- **[拓扑信息查询](https://gitcode.com/cann/hcomm/blob/master/docs/zh/api_ref/comm_opdev/control_plane_api/topo_info_query/README.md)**：查询rank ID、rank数量、拓扑层级、rank间连接关系、Endpoint及可用链路，为资源创建和通信路径选择提供依据。

- **[通信域资源管理](https://gitcode.com/cann/hcomm/blob/master/docs/zh/api_ref/comm_opdev/control_plane_api/comms_domain_resource_mgmt/README.md)**：基于已创建的通信域获取Thread、Channel、HCCL Buffer、远端内存和通信引擎上下文等资源。

- **[基础资源管理](https://gitcode.com/cann/hcomm/blob/master/docs/zh/api_ref/comm_opdev/control_plane_api/basic_resource_mgmt/README.md)**：管理Endpoint、通信内存、Channel和Thread等基础资源的创建、查询与释放。

- **[CCU Kernel生命周期与内存Token管理](https://gitcode.com/cann/hcomm/blob/master/docs/zh/api_ref/comm_opdev/control_plane_api/ccu_kernel_launch_execution/index.md)**：面向CCU通信引擎，提供Kernel注册、下发执行以及内存Token查询能力。

## 数据面

本仓按AICPU和AIV两类通信引擎组织HCOMM数据面接口资料。

- **[AICPU数据面](./aicpu/概述/概述.md)**：通信逻辑在AICPU上执行，并通过任务调度系统调度数据搬运和同步任务，适用于大数据量、高带宽通信场景。本目录中的资料也包含部分Host CPU或CPU_TS场景可调用的接口，具体支持情况以各接口的产品支持情况和约束说明为准。

- **[AIV数据面](https://gitcode.com/cann/hcomm/blob/master/docs/zh/comm_op_dev_guide/aiv_comm_op_dev/README.md)**：通信逻辑由Vector Core执行，适用于对通信时延要求较高的场景。AIV会占用Vector计算核，使用时需要同时考虑通信与计算任务的资源需求。

## AICPU数据面接口

AICPU数据面接口使用控制面准备的通信域、Thread、Channel和通信内存组织通信任务。根据用途分为以下几类：

- **[公共类型](./aicpu/公共类型/公共类型.md)**：介绍数据面接口使用的Thread和Channel句柄、数据类型、规约操作类型及批量传输描述结构。

- **[通信域使用](./aicpu/通信域使用/通信域使用.md)**：根据通信域ID获取并锁定已创建的通信域，使用完成后释放通信域锁。

- **[任务管理](./aicpu/任务管理/任务管理.md)**：以批量或立即执行方式组织数据面操作，并设置任务队列已满时的等待超时时间。

- **[本地数据操作](./aicpu/本地数据操作/本地数据操作.md)**：在本地Device内存之间执行数据拷贝或规约操作。

- **[远端数据操作](./aicpu/远端数据操作/远端数据操作.md)**：通过Channel在本端和对端内存之间执行读、写、规约、带Notify写及批量传输操作。

- **[同步控制](./aicpu/同步控制/同步控制.md)**：实现通信线程之间、通信线程与Runtime任务之间及Channel两端之间的同步，并控制通信任务的执行顺序和完成状态。
