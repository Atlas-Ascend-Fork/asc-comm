This section lists point-to-point communication APIs on the AI Core side. They support submitting read, write, write-notify, atomic operation, and reduction write tasks through `ChannelHandle`, and batch submission through `BatchHandle` (the `COMM_PROTOCOL_UB_CTP` protocol supports single-channel or multi-channel batching, while the `COMM_PROTOCOL_ROCE` protocol supports only single-channel batching).
