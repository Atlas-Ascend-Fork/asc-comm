# Introduction

This section provides the synchronization APIs of CPU_TS Asccomm: `asccomm_cpu_thread_notify_record_on_thread` sends a notification to a target AI CPU thread, and `asccomm_cpu_thread_notify_wait_on_thread` submits a notification wait task to the Host Stream of the local Host CPU thread. The two APIs must be used together.
